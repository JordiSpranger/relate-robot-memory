# Relate Robot Memory

A robot whose whole memory is a graph. It keeps that graph on the robot with Relate and syncs it to Neo4j when the network comes back.

Work in progress for the Relate by Neo4j Hackathon. Setup, run instructions and the persisted store follow as the build lands.
